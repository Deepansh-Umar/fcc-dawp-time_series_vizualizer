# Page View Time Series Visualizer

This project is part of the **Data Analysis with Python** curriculum on [freeCodeCamp.org](https://www.freecodecamp.org/). The goal is to analyze and visualize time series data using Pandas, Matplotlib, and Seaborn.

## 📈 Project Overview

You will visualize time series data using:
- A **line chart** to observe overall trends.
- A **bar chart** to compare monthly averages grouped by year.
- **Box plots** to analyze seasonal and yearly variability.

The dataset contains daily page view counts for the [freeCodeCamp Forum](https://forum.freecodecamp.org/) between **May 9, 2016** and **December 3, 2019**.

---

## 📊 Data Source

The data file is provided as: fcc-forum-pageviews.csv
